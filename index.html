Chuyển đổi ERD sang Mô hình dữ liệu quan hệ

Thực hiện quy trình 4 bước chuyển đổi từ sơ đồ thực thể liên kết (ERD) Quản lý vật tư sang 9 bảng quan hệ chuẩn hóa 1NF-3NF.

🧭 Chi tiết 4 bước chuyển đổi theo giáo trình

Bước 1

Xác định các thực thể chính

Mỗi thực thể mạnh trở thành 1 bảng riêng, thuộc tính định danh làm Khóa chính (PK):

  • PHIEUXUAT: (SoPX, NgayXuat)
  • VATTU: (MaVT, TenVT)
  • PHIEUNHAP: (SoPN, NgayNhap)
  • DONDH: (SoDH, NgayDH)
  • NHACC: (MaNCC, TenNCC, DiaChi)
Bước 2

Xác định các mối quan hệ

Quan hệ 1-N: Đưa PK bên 1 sang làm FK bên N:

  • NHACC (1) → DONDH (n): thêm MaNCC vào DONDH.
  • DONDH (1) → PHIEUNHAP (n): thêm SoDH vào PHIEUNHAP.

Quan hệ N-M: Tạo 3 bảng trung gian:

  • ChiTietPhieuXuat (SoPX, MaVT, DGXuat, SLXuat)
  • ChiTietPhieuNhap (SoPN, MaVT, DGNhap, SLNhap)
  • ChiTietDonDatHang (SoDH, MaVT)
Bước 3

Xử lý thuộc tính đa trị

Trong thực thể NHACC, thuộc tính Số điện thoại (SDT) là đa trị (1 nhà cung cấp có thể có nhiều số).

Để đạt chuẩn 1NF (tính nguyên tử của dữ liệu), tách thành bảng mới:

NHACC_SDT (MaNCC, SDT)
Bước 4

Liệt kê danh sách bảng

Hệ thống hoàn chỉnh gồm 9 bảng quan hệ chuẩn hóa:

  • 5 Bảng thực thể gốc
  • 1 Bảng thuộc tính đa trị
  • 3 Bảng liên kết trung gian (n-m)

💻 Kịch bản SQL hoàn chỉnh (relational_model.sql) 

CREATE DATABASE IF NOT EXISTS quan_ly_vat_tu;
USE quan_ly_vat_tu;

-- 1. Bảng NHACC
CREATE TABLE NHACC (
    MaNCC VARCHAR(20) PRIMARY KEY,
    TenNCC VARCHAR(150) NOT NULL,
    DiaChi VARCHAR(255) NOT NULL
);

-- 2. Bảng thuộc tính đa trị SDT của NHACC
CREATE TABLE NHACC_SDT (
    MaNCC VARCHAR(20),
    SDT VARCHAR(20),
    PRIMARY KEY (MaNCC, SDT),
    FOREIGN KEY (MaNCC) REFERENCES NHACC(MaNCC) ON DELETE CASCADE
);

-- 3. Bảng VATTU
CREATE TABLE VATTU (
    MaVT VARCHAR(20) PRIMARY KEY,
    TenVT VARCHAR(150) NOT NULL
);

-- 4. Bảng DONDH (1-N với NHACC)
CREATE TABLE DONDH (
    SoDH VARCHAR(20) PRIMARY KEY,
    NgayDH DATE NOT NULL,
    MaNCC VARCHAR(20) NOT NULL,
    FOREIGN KEY (MaNCC) REFERENCES NHACC(MaNCC)
);

-- 5. Bảng PHIEUNHAP (1-N với DONDH)
CREATE TABLE PHIEUNHAP (
    SoPN VARCHAR(20) PRIMARY KEY,
    NgayNhap DATE NOT NULL,
    SoDH VARCHAR(20) NOT NULL,
    FOREIGN KEY (SoDH) REFERENCES DONDH(SoDH)
);

-- 6. Bảng PHIEUXUAT
CREATE TABLE PHIEUXUAT (
    SoPX VARCHAR(20) PRIMARY KEY,
    NgayXuat DATE NOT NULL
);

-- 7. Bảng ChiTietDonDatHang (DONDH - VATTU : N-M)
CREATE TABLE ChiTietDonDatHang (
    SoDH VARCHAR(20),
    MaVT VARCHAR(20),
    PRIMARY KEY (SoDH, MaVT),
    FOREIGN KEY (SoDH) REFERENCES DONDH(SoDH),
    FOREIGN KEY (MaVT) REFERENCES VATTU(MaVT)
);

-- 8. Bảng ChiTietPhieuNhap (PHIEUNHAP - VATTU : N-M)
CREATE TABLE ChiTietPhieuNhap (
    SoPN VARCHAR(20),
    MaVT VARCHAR(20),
    DGNhap DECIMAL(15, 2) NOT NULL,
    SLNhap INT NOT NULL,
    PRIMARY KEY (SoPN, MaVT),
    FOREIGN KEY (SoPN) REFERENCES PHIEUNHAP(SoPN),
    FOREIGN KEY (MaVT) REFERENCES VATTU(MaVT)
);

-- 9. Bảng ChiTietPhieuXuat (PHIEUXUAT - VATTU : N-M)
CREATE TABLE ChiTietPhieuXuat (
    SoPX VARCHAR(20),
    MaVT VARCHAR(20),
    DGXuat DECIMAL(15, 2) NOT NULL,
    SLXuat INT NOT NULL,
    PRIMARY KEY (SoPX, MaVT),
    FOREIGN KEY (SoPX) REFERENCES PHIEUXUAT(SoPX),
    FOREIGN KEY (MaVT) REFERENCES VATTU(MaVT)
);
